# Contributing

Pull requests are welcome.

Good additions include:

- dedicated wavetable editors
- browser-based wavetable generators
- synths with serious built-in wavetable editing
- wavetable conversion utilities
- hardware-specific wavetable tools
- documentation about wavetable formats and compatibility

Please include:

- official project link
- short description
- platform, if obvious
- a status note if the project appears abandoned, experimental, or hardware-specific

Please avoid:

- generic WAV editors with no wavetable-specific workflow
- preset/sample packs unless they include useful tooling
- affiliate links
- vague marketing copy

## Style

- Keep entries short. Notes are more valuable than columns — there is no big feature matrix on purpose.
- Prefer official links.
- Avoid prices unless unusually important; prices change.
- Mark uncertain entries as _needs verification_.
- Separate dedicated wavetable tools from synths that merely support wavetable synthesis.

Status tags you can use inline:

```
_Status: active_
_Status: commercial_
_Status: free_
_Status: open source_
_Status: experimental_
_Status: abandoned / unmaintained_
_Status: browser-based_
_Status: Windows-only_
```
